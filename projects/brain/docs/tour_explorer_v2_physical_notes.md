# 自主探索问题的物理描述（`tour_explorer_v2.py` 设计前注）

> 本文是 `src/vrobot/control/tour_explorer_v2.py` 的设计依据。
> 目标任务：机器人探索地图的**可行走区域**，直到完整绘制地图。
> 结论先行：探索不是"导航到一个点"，而是"一个非完整约束的移动观测器，
> 在部分可观测世界里用最小能耗消除地图熵"。
> 下面每一节的问题，都对应 v2 代码里一个显式的结构（状态 / 层 / 异常登记项）。

---

## 1. 机器人本体：一个"只能向前滚"的移动观测器

把机器人抽象成物理系统，它同时受三重约束：

1. **非完整运动学约束**（no-slip）：底盘是差速构型，速度只能沿车身方向，
   不能侧滑。它不像全向质点，更像一辆**无法横移的卡车**：
   想向左走 1 米，必须先转一个朝向角。任何控制律若忽略这一点
   （例如把机器人当质点直接瞄目标），物理上就不可执行或引起绕行。
2. **执行器带宽有限**：角速度不能瞬变——指令是离散帧（20Hz）下发的，
   相邻两帧角速度差有上限（v2：`w_rate_limit`）。等价于转向通道上
   串了一个**惯性飞轮**（角加速度上限）。
3. **感知量程有限**：激光测距传感器的观测半径约 320px，且被占据物遮挡
   （光沿直线传播）。任何时刻，世界只有一小块圆盘对机器人是"可见"的。

**推论**：地图只能靠"移动 + 观察"逐步生长；探索过程因此等价于
**用行走能量换取地图熵减**的运动规划问题（见 §5）。

---

## 2. 反馈控制物理：蛇形摆动/绕圈是一个欠阻尼极限环

对路径跟踪闭环做振动分析：

- 机器人 + 跟踪控制器构成一个**二阶角振动系统**（航向角为广义坐标）。
- 比例转向律（`w ∝ sin α`，即纯追踪 `w = 2v·sinα/L`）对目标方向的
  阶跃扰动响应**欠阻尼**：过冲 → 反向过冲 → 周期摆动；低速+近距离时
  转弯半径 `v/w` 远小于几何半径，弧线切内弧冲过目标 → α 变号 → 以
  `v/w` 为半径绕目标公转。扰动周期性补充能量 → 摆动/绕圈收敛成极限环。

根治手段：**放弃圆弧转向律，改为确定性"对准-直行"**，让闭环只有两个
稳定模态，从结构上消除极限环：

1. `|α| > align_th`：**满速原地转**（固定转速、最短方向，不随 sinα
   缩放——α≈±π 处也不会停转）。α 单调下降，≤ π/angular ≈ 2s 必离开；
2. `|α| ≤ align_th`：**直行** + 小比例航向修正（一阶收敛，无过冲）。

两条配套设计：

- **目标点保证 ≥ lookahead**：前视点沿路径弧长前移且距机器人 ≥ lookahead，
  永不落在脚下（目标在脚下时 `atan2` 对近零向量方向跳变，是另一处打转源头）；
- **最近点投影游标**：游标 = 距机器人最近路径点的单调最大值（而非
  "14px 邻近"推进），切角绕过角点后投影自动跳到更靠后的路点，不卡在角点。

## 3. 指令链路物理：0.5s 无指令即急停 → "走停"

重规划（Dijkstra 距离场 + 射线投影）耗时 0.3–0.5s。若同步执行：

- 规划期间指令流中断，执行端（Godot）是一个**无保持力矩的开环系统**，
  0.5s 收不到指令就急停；
- 机器人做**间歇性受迫运动**：加速—急停—加速，平均速度远低于巡航速度，
  且每次急停都白白消耗加速能量。

物理对策：把重计算搬到**另一条时间轴**（后台规划线程），
控制回路保持 20Hz 恒定带宽，两者用缓冲区解耦——
相当于给控制信号加"不间断电源"。这就是 v2 的异步规划层。

---

## 4. 定位物理：位姿估计会漂，甚至漂出地图

- 里程计误差**随路径长度积分发散**（轮式里程计无绝对基准）；
- 扫描匹配（SLAM）在快速旋转 / 长直线下可能发散，估计位姿会
  **瞬间飘出栅格边界**；
- 位姿出界时，以它为起点的距离场全场为 inf，所有观察点"消失"——
  此时**规划器看到的世界是假的**，任何规划决策都无意义。

物理对策：检测到该状态就**原地冷却等待**（等待位姿图优化 / 新观测
把估计拉回来），而不是误判"探索完成"。

## 5. 信息论物理：地图熵、frontier 与"探索完成"的认识论

### 5.1 熵-能耗权衡

每个候选观察点的价值 = 到达该点后传感器视锥能消除的未知面积
（**信息增益**，射线投影即可估计：光沿直线传播，撞占据即遮挡）；
代价 = 真实路径代价（Dijkstra 距离场，未知区加价——穿越未确认区
有撞上隐藏障碍的**风险项**）。

```
score = gain / (λ + cost)      # 单位能耗的熵减（采集效率）
```

多个观察点串成一条环游（TSP），最小化总行驶能量。

### 5.2 frontier 的物理语义

frontier = 未知区与已确认自由区的边界——物理上是
"光照亮区与阴影的交界线"。走到 frontier 上，传感器视锥就能
把阴影照亮。**frontier 全部消失 = 可行走区域完整绘制**（任务终点）。

### 5.3 "看不到 frontier" ≠ "地图完整"（收敛判定的认识论）

以下三种情况都会表现为"无 frontier 可选"，但物理成因完全不同：

| 现象 | 物理成因 | 正确响应 |
| --- | --- | --- |
| 地图空白 | SLAM 桥接未同步 / 首帧未入图 | 直行探测积累观测，**不是完成** |
| 观察点全被拉黑 | 近期卡死 / 临时不可达（TTL 未到期） | 冷却后重试，**不是完成** |
| 剩余 frontier 物理不可达 | 被障碍封闭的未知碎片 | **真完成** |

判定"真完成"需要**跨越实际位移的多次环游重建而 unknown 几乎不减**
（排除原地搅动的假象）+ **连续多次重建均无有效观察点**——
即用统计证据区分"观测手段暂时耗尽"与"物理上确实无路可走"。

## 6. 异常情况物理清单（v2 异常登记表的设计依据）

探索过程中所有"卡住"的情况，物理上都归为下表之一。
v2 代码用 `Anomaly` 枚举显式登记，每种异常对应一个具名处理函数
（可扩展：新增异常 = 新增枚举项 + 处理器，不改动主循环）。

| 异常 | 物理成因 | 处理（物理动作） |
| --- | --- | --- |
| `FRONT_PANIC` 贴脸障碍 | 传感器视锥内出现近距离占据物（<26px），继续前进必然碰撞 | v=0 原地转向开阔侧（光学比较左右测距均值） |
| `STUCK` 物理卡死 | 3s 窗口内位移 < 6px：驱动指令在，但动量没建立（被顶住） | 丢弃目标，原地转向开阔侧后重规划；**不拉黑目标**（静止可能是外部原因，拉黑会误杀好观察点） |
| `NO_PROGRESS` 绕圈 | 位移检测抓不住的失败：机器人在动（有动量），但路径游标不前进——朝向误差死锁 / 窄角绕行 | 拉黑该观察点（TTL），转向开阔侧，重规划 |
| `PATH_BLOCKED` 动态障碍 | 规划基于过期世界模型：新观测显示剩余路径穿占据区 | 立即作废路径，重规划 |
| `LEG_UNREACHABLE` 腿不可达 | 观察点被后续观测封闭（世界模型更新） | 拉黑该观察点邻域，跳到环游下一腿 |
| `VP_STARVATION` 观察点饥饿 | 合法观察点全部被黑名单屏蔽 | 冷却 150 帧等 TTL 解除；连续 3 次才判完成 |
| `POSE_DRIFT` 位姿漂移 | 估计位姿飘出栅格（§4） | 冷却等待位姿恢复，不做任何规划 |
| `BLANK_MAP` 空图 | 地图自由格 < 阈值（SLAM 未同步） | 直行探测 3s 积累观测，**不宣布完成** |
| `PLANNER_CRASH` 规划异常 | 后台线程未捕获异常（软件层故障） | 记录日志，冷却后重试，不让异常杀死控制线程 |
| `SPIN_LOCK` 打转死锁 | 末段残余碎片多在近旁且身后：纯追踪 α≈±π 处 sin→0 转速趋零且 wrap 变号抖动；转向律 v/w 失配（按巡航速度算 w、实际减速）→ 过转向绕近目标公转；带位移的小半径绕圈会让"位移门控"反复重置而漏判 | 无学习累计**总转角** ≥2 圈（\|dθ\| 求和，地图熵下降即清零；来回画 8 字也计入）→ **高优先级奔赴最近未知区**：放弃环游，锁定最近可达 frontier 自由格直行（`_seeking_unknown` 指令态，优先于环游），学习到新东西后交还环游 |

另有两类**系统级防错**（非异常，但同样物理明确）：

- **防"脚下观察点"死锁**：代价≈0 的近点在 score 下永远赢
  （分母最小），机器人原地选目标→到达→再选同一个→不动。
  对策：观察点必须距机器人 ≥ `vp_min_dist` 格。
- **防 2-opt 假改进震荡**：delta 计算口径不一致会造成虚假改进
  → 无界循环。对策：标准 2-opt delta + 传递次数上限。

## 7. 分层结构：物理时间尺度分离

上述问题的处理频率相差 3 个数量级，因此 v2 沿用物理上的
**时间尺度分层**（快层不受慢层阻塞）：

| 层 | 频率 | 处理的物理问题 |
| --- | --- | --- |
| 层3 反应安全 | 每帧 20Hz | 碰撞动量、卡死动量缺失（§6 前两项） |
| 层2 路径跟随 | 每帧 20Hz | 蛇形极限环、非完整约束（§1 §2） |
| 层1 全局规划 | 事件触发 | 熵-能耗权衡、环游排序（§5） |
| 异步边界 | 线程 | 指令链路急停、位姿漂移（§3 §4） |

层与层之间只通过**明确定义的数据**（当前路径、环游、异常记录）交互，
单写者原则：`_path` / 游标只由主线程写，后台线程只产出待收集结果。

## 8. 全局覆盖意识（CoverageMap）：知道"哪片区域还没探测"

frontier 是**局部、反应式**的：它只标记"未知与已确认自由的交界"，
无法回答"整个场地还有哪片区域没探测"。当残余未知是孤岛 / 被墙围住 /
小于 `min_frontier_size` 的碎片时，frontier 检测不到，机器人要么过早
宣布完成，要么在眼前的局部小边界间来回打转。

全局覆盖图 `CoverageMap` 补上这一层意识（对应代码 `coverage_scale` 等
参数）：

1. **推算场地大小**：已知格（自由∪占据）的外接框 = 对"整个场地有多大"
   的持续估计（随探索增长）；
2. **记录自身位置**：`pose_cell`（每帧更新，机器人在栅格中的位置）；
3. **划分并标记未探测区块**：以 `coverage_scale` 基础格为一粗格，把场地
   边界（外扩 1 粗格）内的区块划分为"已探测 / 未探测"（未探测 = 含 unknown）；
4. **直行奔赴最近未探测区**：高优先级指令态 `_seeking_unknown` 优先锁定
   覆盖图里**最近且可达**的未探测区块中心作为硬目标，A* 直行奔赴（
   `_nearest_unexplored_goal`），不再绕圈。

**大胆选一个方向（承诺 + 迟滞 + 确定性排序）**：左右前方都有未知区且
距离相近时，"每次取最近"会随地图微变在两侧间来回翻转 → 左转右转原地
打转。`_select_seek_goal` 用三招根治（`_committed_goal`）：

- **承诺**：已选目标只要仍在未探测区块且可达，就坚定继续奔赴，直到该
  区块探索完（移出 `unexplored`）或不可达才释放——不因另一侧只近一点点
  就换向；
- **确定性排序**：候选按（距离 → 行 → 列）排序，对称等距时始终取同一侧，
  永不抖动；
- **学习复位**：一旦学到新东西（unknown 下降）即释放承诺，交还环游裁决。

触发时机（全局兜底，不干扰正常环游）：

- `SPIN_LOCK`（无学习打转）→ 奔赴最近未探测区；
- 环游耗尽且 `find_clusters` 无 frontier、但覆盖图仍有未探测区块
  （孤岛 / 小碎片）→ 奔赴，而非过早宣布完成（轮数受 `seek_max_rounds`
  限制，防不可达死循环）；
- **闭环补齐**（`_completing`）：场地边界稳定 `completion_stable` 帧
  （≈ 地图闭环，已推算整个场地大小）但仍有未探测区 → 进入补齐模式，
  直行扫尽中部/剩余未探测区，直到 `unexplored` 清空（整个地图都被
  激光扫过）才交还环游裁决。补齐模式跨学习事件持续（学习只是把目标
  推进到下一块未探测区），不被打断；
- 一旦学到新东西（unknown 下降）→ 退出**逃逸式**指令态（`_seeking_unknown`），
  交还环游裁决（补齐模式 `_completing` 例外，见上）。
