一、问题定义：定位的三层结构

"机器人定位"在工程上其实是三个层次不同的问题，选型前先分清自己要解决哪一层：

层次要解决的问题典型技术
① 里程计（Odometry） 估计相对运动（帧间/短时位姿增量），无需地图。轮式里程计、IMU、视觉里程计（VO）、激光里程计（LO）。 轮速计 + IMU 融合、EKF、VINS 前端、FAST-LIO 前端
② SLAM（无图定位） 在未知环境中"边建图边定位"，解决鸡生蛋问题，需要回环检测消除累计漂移。 ORB-SLAM3、Cartographer、FAST-LIO2、LIO-SAM、RTAB-Map
③ 重定位（有图定位） 在已有地图上实时确定位姿，是部署态（运营态）的主流形态， SLAM 只在建图/初始化阶段使用一次。 AMCL 粒子滤波、NDT/ICP 点云匹配、视觉重定位（词袋/学习描述子）
关键认知：绝大多数商用机器人（扫地机、配送机器人、AGV）的日常运行都是 "一次 SLAM 建图 + 长期地图定位" 模式。SLAM 解决的是"第一次来怎么画地图"，重定位解决的是"每天都在这里怎么走"。

二、十年演进（2015–2025）

从你上次了解 SLAM 至今，范式的变化可以概括为：滤波 → 图优化 → 紧耦合融合 → 学习赋能 → 神经/显式神经表示 → 大模型语义。

图 1：SLAM 技术范式演进主线（精度从米级演进到厘米/毫米级）
阶段核心特征代表算法
2015–2017手工特征（ORB/SIFT）+ 滤波（EKF/粒子滤波）或 BA 图优化；2D 激光栅格地图；精度米级，离线或准实时。ORB-SLAM1/2、LSD-SLAM、Gmapping、Cartographer（2016）
2017–2019视觉-惯性紧耦合（VIO）成为标配，解决单目尺度不确定；直接法兴起；深度学习开始替换手工特征。VINS-Mono/Fusion、OKVIS、DSO、SuperPoint + SuperGlue
2019–2021激光-惯性紧耦合（LIO）爆发；图优化成为后端绝对主流（g2o / Ceres / GTSAM）；BEV 多传感器融合在自动驾驶落地。LIO-SAM、FAST-LIO/2、Faster-LIO、Kimera
2021–2023神经隐式表示（NeRF）进入 SLAM，实现稠密照片级建图；3DGS（2023）以显式高斯表示实现实时渲染，迅速取代 NeRF-SLAM 成为研究热点。iMAP、NICE-SLAM、Co-SLAM、GS-SLAM、SplaTAM、MonoGS
2023–2026学习型/端到端 SLAM（DROID-SLAM 一系）与 3DGS 结合；语义 SLAM + 大模型/VLA 推动导航从"几何定位"走向"认知导航"，具身智能成为新范式。DROID-SLAM、DROID-Splat、NaVid、各类 VLA 导航模型
市场现状（2025）：视觉 SLAM 占约 58% 部署份额（AR/手机/无人机/服务机器人），激光 SLAM 约 42%（工业、仓储、自动驾驶）。机器人是 SLAM 最大应用场景（约 40%）。国内厂商（华为、小鹏、宇树、银河通用等）已从跟随者变为主要贡献者，3D 激光雷达价格大幅下降（单线雷达已降至数百元级），是激光方案普及的关键推手。

三、激光 SLAM（2D 与 3D / LIO）

原理：用激光雷达的点云做扫描匹配（Scan Matching，如 ICP、NDT、特征点配准），得到帧间运动估计，再由后端图优化 + 回环检测消除漂移。激光测距直接、精确、不受光照影响，定位精度可达 ±5cm 甚至毫米级，是工业场景的首选。

3.1 2D 激光 SLAM（室内机器人主力）

算法技术路线特点与适用开源
GmappingRao-Blackwellized 粒子滤波（RBPF）经典老牌，依赖里程计，CPU 占用低；适合小场景，但大场景粒子数爆炸，已属"成熟但较旧"。ROS openslam_gmapping
Cartographer子图（submap）+ 分支定界回环 + 图优化谷歌开源，2D/3D 通吃，回环质量高，仍是"效果最好"之一；但工程复杂、调参门槛高。cartographer_project
slam_toolbox图优化 + 序贯建图，支持终身建图/地图序列化ROS2 生态默认推荐，活跃维护、易用性好，支持"边走边存、断点续建"，室内移动机器人首选。stevemacenski/slam_toolbox

3.2 3D 激光 SLAM 与 LIO（激光-惯性里程计）

算法核心思想特点与适用
LOAM 系列
LOAM / LeGO-LOAM / A-LOAM / F-LOAM		提取角点 + 平面点特征做帧间匹配；里程计（高频低精度）与建图（低频高精度）双线程分离。3D 激光 SLAM 开山之作；LeGO-LOAM 做地面优化，适合地面机器人，轻量可在嵌入式跑。无回环，长时漂移需额外处理。
LIO-SAM（2020）因子图紧耦合 LiDAR + IMU（+ 可选 GPS），IMU 预积分，支持回环与 GPS 因子。室外大场景、自动驾驶经典方案，全局一致性好；基于 GTSAM 的 iSAM2 增量优化。
FAST-LIO2（2021）迭代误差状态卡尔曼滤波（IESKF）紧耦合；直接配准原始点云（免特征提取）；ikd-Tree 增量式地图。速度极快（可达 100Hz 级更新）、资源占用低，是当前工程落地最广的 LIO；缺点是纯滤波无全局回环，长航时需配合图优化框架。
Faster-LIO（2021）FAST-LIO2 思路 + 增量稀疏体素（iVox）替代 kd-tree，并行近邻查询。更快、更省内存，国内作者（高翔）开源，工程性能优秀。
Point-LIO（2023）逐点（point-by-point）LIO，把 IMU 建模为输出，高频逐点更新。应对剧烈运动/高动态场景（快速旋转、颠簸），鲁棒性极强。
深度学习加持
SuMa++、C-LOAM、OverlapNet		语义分割剔除动态物体点云 / 学习点云重叠度描述子做回环。动态场景（行人、车辆密集）鲁棒性显著提升。
选型要点：FAST-LIO2 系（快、轻、准）适合大多数新项目起步；需要全局一致性/大范围建图时，在其外加回环与图优化（如与 LIO-SAM 思路结合或使用 FAST-LIO-SLAM）。

四、视觉 SLAM 与 VIO

原理：用相机（单目/双目/RGB-D）提取图像特征或像素灰度，通过对极几何 / PnP / 光度误差估计相机运动，三角化恢复地图点，后端 BA 优化 + 回环检测（词袋 DBoW2 / 学习描述子）。优点是传感器便宜、语义信息丰富；缺点是依赖纹理与光照、单目有尺度不确定性。

特征法路线 主流

ORB-SLAM3（2021，T-RO）——视觉 SLAM 的"黄金标准"：单目/双目/RGB-D/鱼眼全支持，视觉-惯性紧耦合，Atlas 多地图管理，回环 + 重定位完备。CPU 实时，精度标杆。

弱点：弱纹理（白墙走廊）、低照度、动态物体场景退化。

GitHub: UZ-SLAMLab/ORB_SLAM3

直接法路线 轻量

LSD-SLAM / DSO（直接稀疏里程计）——不提特征点，直接最小化像素光度误差，利用全部像素信息，高速运动与弱纹理下比特征法稳，计算集中在少数高梯度像素，适合嵌入式。

弱点：需光度标定，对光照剧烈变化敏感。

GitHub: tum-vision/dso

视觉-惯性（VIO）标配

VINS-Mono / VINS-Fusion（港科大）——滑窗优化 + IMU 预积分紧耦合，VINS-Fusion 扩展双目/GPS。解决单目尺度不确定，快速旋转、运动模糊下更鲁棒，是无人机与 AR 设备的主流方案。

GitHub: HKUST-Aerial-Robotics/VINS-Fusion

RGB-D 稠密/通用 易用

RTAB-Map——增量词袋回环 + 图优化，输出稠密 3D 网格/八叉树地图；RGB-D/双目/LiDAR 通吃，ROS/ROS2 集成度最高、上手最友好，适合快速做出能跑的机器人。

GitHub: introlab/rtabmap

五、多传感器融合 SLAM

单一传感器各有盲区：相机怕黑怕动，激光怕雨雾怕玻璃，IMU 快而漂，轮速计打滑失效。融合的本质是"互补 + 冗余"。2026 年的共识：紧耦合（tightly-coupled）联合优化是性能上限，松耦合只是工程妥协。

系统传感器组合特点
LVI-SAM（2021）LiDAR + 相机 + IMULIO-SAM 与 VINS-Mono 的紧耦合合体，二者互为退 fallback，视觉特征辅助激光退化场景。
R2LIVE / FAST-LIVO2LiDAR + IMU + RGB港科大 MARS 实验室系；FAST-LIVO2 被认为是"有激光有相机条件下"的 Top1 选择，弱纹理与实时性俱佳。
工况增强+ GPS/RTK、UWB、轮速计、磁力计室外加 GNSS/RTK 因子（LIO-SAM 原生支持），室内可用 UWB 做绝对位置锚点，轮式机器人必加轮速计。

六、学习型 / 端到端 SLAM

深度学习在 SLAM 各模块的渗透已成主流，但"完全端到端取代几何"尚未在工业界定型。当前格局是"学习组件 + 几何后端"的混合形态：

  • 前端特征替换：SuperPoint（自监督特征点）+ SuperGlue / LightGlue（学习匹配）在弱纹理、光照变化下显著优于 ORB，代价是需要 GPU 或较强算力。
  • 端到端稠密 SLAM：DROID-SLAM（2021）用循环迭代的光流-BA 网络直接输出位姿与深度，在动态/困难序列上精度 SOTA，但算力开销大（需桌面级 GPU），后续轻量化版本（如 DPVO/DPV-SLAM）持续降低门槛。
  • 学习回环/重定位：NetVLAD、OverlapNet（点云重叠描述子）、场景坐标回归（SCoRe 类）提升长廊、重复纹理等退化场景的重定位成功率。
  • 动态物体处理：语义分割（Mask R-CNN / YOLO）+ 几何一致性判别（如 DynaSLAM、DS-SLAM），把行人等动态物从特征与地图中剔除。
判断：学习模块已经"值得用"（特征、回环、深度补全），但经典几何后端（优化/滤波）仍是可靠性的压舱石；纯端到端方案目前主要在 GPU 充足的研究与自动驾驶数据平台中使用。

七、神经隐式与 3DGS SLAM（2023 至今最热方向）

定位之外，"地图长什么样"发生了革命：NeRF（2020，隐式 MLP 辐射场）首次实现照片级稠密重建；3D Gaussian Splatting（2023）用数百万个显式高斯椭球表示场景，可微光栅化渲染，训练快、渲染实时（100+ FPS 级），迅速成为 SLAM 稠密建图的新载体。

代表系统表示方式特点
NICE-SLAM / Co-SLAM / Point-SLAMNeRF 隐式网格/哈希/点特征RGB-D 输入，几何稠密精度高，但渲染慢、实时性受限。
SplaTAM（2024）3DGS，纯 RGB/RGB-D稠密光度跟踪 + 高斯地图联合优化，GS-SLAM 代表作。
MonoGS（2024）3DGS，单目单目流增量初始化高斯，用光流先验缓解尺度漂移。
Photo-SLAM / GS-SLAM3DGS + 几何稠密化多相机模态、渲染保真度与几何精度平衡。
DROID-Splat（ICCVW 2025）端到端跟踪 + 3DGS 渲染DROID 系跟踪 + GS 渲染，跟踪与渲染双 SOTA；支持未知内参。
RTG-SLAM / EndoGSLAM3DGS 工程化大场景 17+ FPS、内窥镜 100+ FPS，证明可扩展性。
现状判断：3DGS-SLAM 当前更多是"高质量建图"而非"高可靠定位"方案——内存开销大（城市级场景需数 GB 显存）、增量建图存在"灾难性遗忘"、缺乏统一基准、动态环境鲁棒性仍在攻关。机器人上落地建议先用于离线高保真重建/数字孪生，跟踪定位仍交给传统 VIO/LIO。

八、语义 SLAM 与大模型导航（具身智能方向）

这是 2024–2026 变化最大、也最"未来"的方向：定位从"我在哪"升级为"我在哪 + 我看到的是什么 + 我该怎么去"。

  • 语义 SLAM：地图对象化——地标不再是点云，而是"冰箱、门、电梯"等语义实体（Kimeria、Hydra 等场景图 SLAM）。价值在于：动态物过滤、人类可交互（"去充电桩旁"）、地图复用与终身 SLAM。
  • 视觉语言导航（VLN）与大模型：NaVid 等视频大模型直接"看画面 + 听指令 → 输出动作"；NavGPT 类用 LLM 做推理规划；VLA（视觉-语言-动作）模型推动端到端具身导航，2025 年被业界称为 VLA-SLAM 元年趋势。
  • 开放词汇地图：CLIP/ grounded SAM 等把开放词汇语义嵌入 3DGS/点云地图，机器人可用自然语言查询地图。
务实建议：大模型导航尚不适合做定位的"安全底层"，适合做任务理解与规划的上层；底层定位仍需几何算法兜底，两者分层组合。

九、基于已有地图的定位（部署态主流）

机器人量产部署的日常状态：地图已建好，只需实时确定位姿。

方法原理适用
AMCL（自适应蒙特卡洛定位）粒子滤波：用一组带权粒子表示位姿分布，激光观测更新权重、重采样收敛。2D 栅格地图定位的事实标准，ROS/Nav2 内置；参数少、可靠性高，室内 ±5cm 可达。
NDT / ICP 点云匹配定位当前帧点云与 3D 点云地图配准求解位姿（NDT 用高斯分布近似、ICP 直接最近点迭代）。3D 激光机器人与自动驾驶标配；长廊/隧道等几何退化场景需融合 IMU/GNSS 兜底。
视觉重定位词袋检索关键帧 → PnP 求位姿；或学习描述子/场景坐标回归。AR 设备、视觉机器人启动时"找回自己"；ORB-SLAM3 内置重定位模块。
绝对定位补充GNSS/RTK、UWB 信标、蓝牙指纹、二维码/反光板高精度需求（±2cm 级）或 SLAM 退化环境（大空旷、重复纹理）的兜底手段，工业 AGV 常用反光板 + SLAM 混合。

11.2 方案 B：视觉为主 / 无人机 / 小型平台

ORB-SLAM3（双目或 RGB-D + IMU）或 VINS-Fusion；快速原型用 RTAB-Map（ROS2 集成好，支持纯视觉也支持多传感器）。学习特征增强可用 SuperPoint + LightGlue 替换前端（需 GPU）。

11.3 方案 C：3D 激光 / 室外 / 高精度

FAST-LIO2 / Point-LIO 做里程计 → 需要全局一致性时接回环图优化（FAST-LIO-SLAM 或 LIO-SAM）；定位态用 NDT/ICP 匹配 3D 地图 + robot_localization 融合 IMU/轮速/GNSS。室外可加 RTK-GNSS 因子。

十二、趋势总结与本项目建议

12.1 五大趋势

  1. 紧耦合融合是基本盘：单传感器方案只存在于成本极限场景；"LiDAR + IMU + 相机 + 轮速"紧耦合已是工业默认。
  2. 地图表示革命：从稀疏点云/栅格 → 稠密网格 → NeRF → 3DGS 显式高斯，建图保真度指数级提升，3DGS 正在成为新的"地图标准格式"。
  3. 学习组件全面渗透：特征提取、匹配、回环、深度估计已被神经网络替代或增强；端到端 SLAM（DROID 系）在算力允许时精度领先。
  4. 语义化与终身化：地图从几何走向"场景图 + 开放词汇语义"，支持人机对话式导航与长期地图维护（终身 SLAM）。
  5. 大模型上桌：VLA / VLN 让"导航"从算法问题部分变成大模型问题，但安全兜底仍是经典几何定位，分层架构是共识。

12.2 对 VirtualRobot 项目的建议

本项目当前是 Godot + Python 独立大脑架构的虚拟机器人。定位调研对它的落地路径建议：
  • 仿真内验证优先：先用 Godot 侧输出的虚拟传感器数据（模拟激光扫描、相机、IMU）验证算法流程，再迁移真机——这与 Gazebo/Isaac 的行业惯例一致。
  • 建议起步组合：方案 A（2D 激光 + slam_toolbox + AMCL + Nav2）作为基线，复杂度最低、资料最多；Python 大脑可通过 ROS2 桥接或在仿真内复现简化版粒子滤波定位。
  • 进阶方向：若目标是照片级仿真地图与具身智能实验，可关注 3DGS（SplaTAM/MonoGS）与语义 SLAM；若做导航决策研究，关注 VLA/大模型导航的分层的架构（大模型规划 + 几何定位兜底）。
