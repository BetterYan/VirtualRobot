# VirtualRobot 项目总览

> 扫地机器人仿真项目。当前阶段：**Godot 无图传感器仿真 + Python 端 2D SLAM 算法验证**。

## 1. 项目定位

- **虚拟世界层**：Godot 4，负责房间场景、机器人实体、物理碰撞与**传感器仿真**（2D 激光雷达、带噪里程计）。以"无图模式"运行——不向算法端提供任何地图与真值位姿
- **算法层**：Python 独立进程（`projects/brain`），只依赖传感器流，自行建图与定位；当前验证 **2D 激光 SLAM**（方案 A，见《03-机器人定位算法调研》），后续扩展粒子滤波/图优化/3D/VSLAM
- **真值评估**：Godot 另发一路 `ground_truth` 独立通道，仅用于算法精度评估，算法代码层面隔离
- **历史阶段**：一期 Godot 一体式覆盖清扫（弓字形 CPP + A* + 回充）已保留可运行，其算法将作为"开天眼对照"并在算法成熟后移植回 Python 端

## 3. 子项目职责

| 子项目 | 职责 |
|--------|------|
| `projects/godot/` | 物理世界仿真：场景、碰撞、激光雷达/里程计仿真（带噪声）、键盘遥控、渲染；**无图模式下不泄漏地图** |
| `projects/brain/` | 全部定位建图算法：2D SLAM（扫描匹配 + 占据栅格）、通信服务端、实时可视化、真值评估；后续扩展规划与导航 |

## 4. 演进路线

```
一期：Godot 一体式覆盖清扫（已完成，保留）
                                        │
二期（当前）：大脑外置 + 无图 SLAM        ▼
  Godot = 纯传感器仿真器 ←WebSocket→ Python 2D SLAM（扫描匹配+占据栅格）
                                        │
三期：算法深化                           ▼
  RBPF 粒子滤波 → 图优化回环 → 覆盖规划移植回 Python → 动态场景
                                        │
四期：维度与模态扩展                      ▼
  3D SLAM / VSLAM（相机传感器）→ 语义地图 → 大模型导航上层
```

关键原则：**算法端永远不知道世界的真面目**——只允许从带噪传感器流中重建认知；真值仅存在于评估通道。
